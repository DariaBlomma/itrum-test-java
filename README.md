# Wallet Service

Решение тестового задания ([текст задания](TASK.md)) на позицию Java-разработчика.

## Технологии

- **Java 17**
- **Spring Boot 3**
- **PostgreSQL 15**
- **Liquibase** 
- **HikariCP** 
- **Maven**
- **Docker** / **Docker Compose**
- **JUnit 5** / **Mockito** 

## Запуск приложения

### 1. Запуск через Docker Compose

```bash
# Собрать проект
./mvnw clean package

# Полная пересборка и запуск
docker-compose up --build -d

# Приложение доступно по адресу:
`http://localhost:8080/api/v1`
```

# Остановить контейнеры (сохраняются данные)
docker-compose stop

# Остановить и удалить контейнеры
docker-compose down

# Остановить, удалить контейнеры и volumes (все данные)
docker-compose down -v

## Подход к тестированию

В проекте используется **Чикагская школа (Detroit/classical style)** юнит-тестирования, описанная в книге Владимира Хорикова **"Принципы Юнит-тестирование"** (примеры на C#, но применимы к любому языку). Основные принципы:

- **Тесты проверяют конечное состояние**, а не взаимодействия между объектами
- **Минимум моков** — только для внешних систем (база данных, API)
- **Фокус на результате**, а не на том, как он достигнут

Это обеспечивает надежные тесты, устойчивые к рефакторингу, и высокую скорость выполнения.

## Нагрузочное тестирование

### Установка wrk

**Linux (Ubuntu/Debian):**
```bash
sudo apt-get install wrk
```

### Тестирование GET запроса

```bash
wrk -t10 -c100 -d30s http://localhost:8080/api/v1/wallets/11111111-1111-1111-1111-111111111111
```

### Тестирование POST запроса

Запустите тест (файл post.lua находится в корне проекта):
 
```bash
wrk -t10 -c100 -d30s -s post.lua http://localhost:8080/api/v1/wallet
```
